    HCP Backup Procedures¶

    Step-by-step backup procedures for Hosted Control Planes.

    Prerequisites¶

    • oc CLI installed and authenticated as cluster-admin
    • OADP Operator installed (./scripts/01-install-oadp.sh)
    • S3 credentials configured
    • DataProtectionApplication deployed and ready

    Verify Prerequisites¶

    # Check OADP status
oc get dpa -n openshift-adp

# Check BackupStorageLocation
oc get backupstoragelocation -n openshift-adp

# Verify velero pods
oc get pods -n openshift-adp

    Procedure 1: Manual Control Plane Backup¶

    Step 1: Identify the Hosted Cluster¶

    # List all hosted clusters
oc get hostedcluster -A

# Example output:
# NAMESPACE   NAME      VERSION   KUBECONFIG                    PROGRESS    AVAILABLE
# clusters    my-hcp    4.18.2    my-hcp-admin-kubeconfig       Completed   True

    Record: - Cluster Name: __ - Namespace: __

    Step 2: Identify Control Plane Namespace¶

    The control plane namespace follows the pattern: <namespace>-<cluster-name>

    # Verify control plane namespace exists
oc get namespace clusters-my-hcp

# Check control plane pods
oc get pods -n clusters-my-hcp

    Step 3: Verify Cluster Health Before Backup¶

    # Check HostedCluster status
oc get hostedcluster my-hcp -n clusters -o jsonpath='{.status.conditions}' | jq

# Check NodePool status
oc get nodepool -n clusters -l hypershift.openshift.io/cluster=my-hcp

# Verify etcd is healthy
oc get pods -n clusters-my-hcp -l app=etcd

    Step 4: Execute Backup¶

    # Run backup script
./scripts/02-backup-control-plane.sh my-hcp clusters

    The script will: 1. Verify the hosted cluster exists 2. Verify control plane namespace exists 3. Check OADP readiness 4. Pause HostedCluster and NodePool reconciliation 5. Create the Backup CR

    Step 5: Monitor Backup Progress¶

    # Watch backup status
oc get backup -n openshift-adp -w

# Get detailed status
oc describe backup hcp-my-hcp-<timestamp> -n openshift-adp

# Check for errors
oc get backup hcp-my-hcp-<timestamp> -n openshift-adp \
  -o jsonpath='{.status.phase} - Errors: {.status.errors}'

    Step 6: Verify Backup Completion¶

    # Use verification script
./scripts/verify-backup.sh hcp-my-hcp-<timestamp>

    Expected output for successful backup: 

    ✓ Backup is valid and can be used for restore

    Step 7: Resume Reconciliation¶

    # Resume HostedCluster
oc patch hostedcluster my-hcp -n clusters --type=merge \
  -p '{"spec":{"pausedUntil":null}}'

# Resume NodePools
oc patch nodepool my-hcp-workers -n clusters --type=merge \
  -p '{"spec":{"pausedUntil":null}}'

    Step 8: Document Backup¶

    Record in backup log: - Date/Time: __ - Backup Name: __ - Cluster: __ - Status: __ - Operator: ___

    Procedure 2: Scheduled Backup Configuration¶

    Step 1: Configure Schedule¶

    Edit the schedule template with your values:

    export HOSTED_CLUSTER_NAMESPACE="clusters"
export HOSTED_CONTROL_PLANE_NAMESPACE="clusters-my-hcp"

    Step 2: Apply Schedule¶

    envsubst < manifests/06-backup-schedule.yaml.template | oc apply -f -

    Step 3: Verify Schedule¶

    # Check schedule exists
oc get schedule -n openshift-adp

# Check next run time
oc get schedule hcp-daily-backup -n openshift-adp -o yaml

    Step 4: Monitor Scheduled Backups¶

    # List backups created by schedule
oc get backup -n openshift-adp -l velero.io/schedule-name=hcp-daily-backup

    Procedure 3: Pre-Upgrade Backup¶

    Always take a backup before upgrading the management cluster or hosted clusters.

    Step 1: Take Manual Backup¶

    export BACKUP_NAME="pre-upgrade-$(date +%Y%m%d)"
./scripts/02-backup-control-plane.sh my-hcp clusters

    Step 2: Verify Backup¶

    ./scripts/verify-backup.sh "${BACKUP_NAME}"

    Step 3: Document Pre-Upgrade State¶

    Record: - Current HCP version: __ - Target HCP version: __ - Management cluster version: __ - Backup name: __ - Verified by: ___

    Procedure 4: Data Plane Backup (Optional)¶

    Only needed if you want to backup workloads running ON the hosted cluster.

    Prerequisites¶

    • OADP must be installed on the hosted cluster (not just management cluster)
    • Kubeconfig for the hosted cluster

    Step 1: Get Hosted Cluster Kubeconfig¶

    oc get secret my-hcp-admin-kubeconfig -n clusters \
  -o jsonpath='{.data.kubeconfig}' | base64 -d > /tmp/my-hcp-kubeconfig

    Step 2: Install OADP on Hosted Cluster¶

    export KUBECONFIG=/tmp/my-hcp-kubeconfig
./scripts/01-install-oadp.sh

    Step 3: Backup Application Namespace¶

    ./scripts/03-backup-data-plane.sh my-app /tmp/my-hcp-kubeconfig

    Troubleshooting¶

    Backup Stuck in "InProgress"¶

    # Check velero pod logs
oc logs -n openshift-adp -l app.kubernetes.io/name=velero

# Check node-agent pods (for volume backups)
oc logs -n openshift-adp -l app.kubernetes.io/name=node-agent

    Backup Failed¶

    # Get failure details
oc describe backup <backup-name> -n openshift-adp

# Check backup logs
velero backup logs <backup-name>

    S3 Connection Issues¶

    # Verify BackupStorageLocation
oc get backupstoragelocation -n openshift-adp -o yaml

# Check credentials
oc get secret cloud-credentials -n openshift-adp -o yaml

    Quick Reference¶

    Command Description
    ./scripts/02-backup-control-plane.sh <name> <ns> Manual backup
    ./scripts/verify-backup.sh List all backups
    ./scripts/verify-backup.sh <name> Verify specific backup
    oc get backup -n openshift-adp List backups
    oc get schedule -n openshift-adp List schedules
