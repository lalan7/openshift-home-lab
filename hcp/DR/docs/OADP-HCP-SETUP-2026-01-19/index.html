    OADP HCP Backup Setup - Step by Step¶

    Date: 2026-01-19
    Cluster: management-hypershift-lab
    Hosted Cluster: sno-hcp (namespace: clusters)
    Control Plane Namespace: clusters-sno-hcp

    Overview¶

    This document captures the step-by-step process to configure OADP (OpenShift API for Data Protection) to backup HCP (Hosted Control Planes) including etcd data using ODF RGW as the S3 backend.

    Prerequisites Verified¶

    Requirement Status
    ODF installed ✅
    RGW StorageClass available ✅ ocs-storagecluster-ceph-rgw
    etcd PVC using RBD ✅ data-etcd-0 (4Gi)
    VolumeSnapshotClass available ✅ ocs-storagecluster-rbdplugin-snapclass
    cluster-admin access ✅

    Step 1: Verify RGW S3 Storage¶

    Before setting up OADP, we verified that ODF RGW was working correctly.

    1.1 Check RGW Pods¶

    oc get pods -n openshift-storage | grep rgw
    Result: rook-ceph-rgw-ocs-storagecluster-cephobjectstore-a-* running (2/2)

    1.2 Check RGW StorageClass¶

    oc get sc | grep rgw
    Result: ocs-storagecluster-ceph-rgw available

    1.3 Test S3 Connectivity¶

    Created a test pod to verify S3 operations: 

    # Create test pod with aws-cli
oc apply -f - <<EOF
apiVersion: v1
kind: Pod
metadata:
  name: rgw-s3-test
  namespace: odf-test
spec:
  containers:
  - name: aws-cli
    image: amazon/aws-cli:latest
    command: ["sleep", "3600"]
    env:
    - name: AWS_ACCESS_KEY_ID
      valueFrom:
        secretKeyRef:
          name: test-bucket
          key: AWS_ACCESS_KEY_ID
    - name: AWS_SECRET_ACCESS_KEY
      valueFrom:
        secretKeyRef:
          name: test-bucket
          key: AWS_SECRET_ACCESS_KEY
    - name: S3_ENDPOINT
      value: "https://rook-ceph-rgw-ocs-storagecluster-cephobjectstore.openshift-storage.svc:443"
    - name: S3_BUCKET
      valueFrom:
        configMapKeyRef:
          name: test-bucket
          key: BUCKET_NAME
  restartPolicy: Never
EOF

    1.4 Verified S3 Operations¶

    oc exec -n odf-test rgw-s3-test -- sh -c '
  # Upload
  echo "test" > /tmp/test.txt
  aws s3 cp /tmp/test.txt s3://$S3_BUCKET/ --endpoint-url $S3_ENDPOINT --no-verify-ssl

  # Download
  aws s3 cp s3://$S3_BUCKET/test.txt /tmp/downloaded.txt --endpoint-url $S3_ENDPOINT --no-verify-ssl

  # Delete
  aws s3 rm s3://$S3_BUCKET/test.txt --endpoint-url $S3_ENDPOINT --no-verify-ssl
'
    Result: All operations successful ✅

    1.5 Cleanup Test Pod¶

    oc delete pod rgw-s3-test -n odf-test

    Step 2: Install OADP Operator¶

    2.1 Run Installation Script¶

    cd /Users/elalance/Documents/code/MYHOMELAB/hcp/DR
./scripts/01-install-oadp.sh

    2.2 What the Script Does¶

    1. Creates openshift-adp namespace
    2. Creates OperatorGroup
    3. Subscribes to redhat-oadp-operator (stable-1.4 channel)
    4. Waits for CSV to be ready

    2.3 Verify Installation¶

    oc get pods -n openshift-adp
    Result: openshift-adp-controller-manager-* running

    OADP Version: v1.4.7

    Step 3: Create RGW Bucket and Credentials¶

    3.1 Run Credentials Setup Script¶

    ./scripts/setup-rgw-credentials.sh

    3.2 What the Script Does¶

    1. Creates ObjectBucketClaim oadp-hcp-bucket in openshift-adp namespace
    2. Waits for OBC to be bound
    3. Extracts credentials from OBC secret
    4. Creates cloud-credentials secret in Velero format

    3.3 Created Resources¶

    ObjectBucketClaim: 

    apiVersion: objectbucket.io/v1alpha1
kind: ObjectBucketClaim
metadata:
  name: oadp-hcp-bucket
  namespace: openshift-adp
spec:
  generateBucketName: oadp-hcp-backup
  storageClassName: ocs-storagecluster-ceph-rgw

    Bucket Created: oadp-hcp-backup-efc2a666-b4ac-42d7-bd6e-b6d70a85fd90

    Credentials Secret: cloud-credentials (Velero format)

    Step 4: Deploy DataProtectionApplication¶

    4.1 Run DPA Deployment Script¶

    ./scripts/deploy-dpa-rgw.sh

    4.2 What the Script Does¶

    1. Verifies prerequisites (OADP operator, credentials)
    2. Gets bucket name from OBC ConfigMap
    3. Deploys DPA with RGW configuration
    4. Waits for BackupStorageLocation to be available

    4.3 DPA Configuration¶

    apiVersion: oadp.openshift.io/v1alpha1
kind: DataProtectionApplication
metadata:
  name: hcp-dpa
  namespace: openshift-adp
spec:
  backupLocations:
    - velero:
        config:
          s3Url: https://rook-ceph-rgw-ocs-storagecluster-cephobjectstore.openshift-storage.svc:443
          s3ForcePathStyle: "true"
          insecureSkipTLSVerify: "true"  # Self-signed cert
          region: us-east-1
        credential:
          key: cloud
          name: cloud-credentials
        objectStorage:
          bucket: oadp-hcp-backup-efc2a666-b4ac-42d7-bd6e-b6d70a85fd90
          prefix: hcp-backups
        provider: aws
  configuration:
    nodeAgent:
      enable: true
      uploaderType: kopia
    velero:
      defaultPlugins:
        - openshift
        - aws
        - csi

    4.4 Verify DPA Status¶

    oc get dpa -n openshift-adp
oc get backupstoragelocation -n openshift-adp
    Result: hcp-dpa-1 BackupStorageLocation is Available

    Step 5: Configure CSI Snapshots¶

    5.1 Label VolumeSnapshotClass for Velero¶

    For CSI snapshots to work with Velero, the VolumeSnapshotClass needs a label:

    oc label volumesnapshotclass ocs-storagecluster-rbdplugin-snapclass \
  velero.io/csi-volumesnapshot-class=true

    5.2 Verify Label¶

    oc get volumesnapshotclass ocs-storagecluster-rbdplugin-snapclass -o yaml | grep -A5 labels

    Step 6: Fix Backup Template¶

    6.1 Issue Discovered¶

    The backup template referenced storageLocation: default but the actual BackupStorageLocation was named hcp-dpa-1.

    6.2 Fix Applied¶

    Updated manifests/backup-control-plane.yaml.template: 

    # Before
storageLocation: default

# After
storageLocation: hcp-dpa-1

    Also updated the label: 

    labels:
  velero.io/storage-location: hcp-dpa-1

    Step 7: Take First Backup¶

    7.1 Run Backup Script¶

    ./scripts/02-backup-control-plane.sh sno-hcp clusters

    7.2 What the Script Does¶

    1. Verifies HostedCluster exists
    2. Verifies control plane namespace exists
    3. Pauses HostedCluster reconciliation
    4. Creates Backup CR with CSI volume snapshots

    7.3 Monitor Backup Progress¶

    oc get backup -n openshift-adp -w

    7.4 Backup Results¶

    Metric Value
    Backup Name hcp-sno-hcp-20260119-132459
    Status Completed
    Items Backed Up 220
    Errors 0
    Warnings 0
    Duration 38 seconds

    Step 8: Verify etcd Data Backup¶

    8.1 Check DataUploads (CSI Data Mover)¶

    oc get dataupload -n openshift-adp -l velero.io/backup-name=hcp-sno-hcp-20260119-132459

    Result: | Name | Status | Bytes | |------|--------|-------| | hcp-sno-hcp-20260119-132459-8hvxw | Completed | 417,748,384 (417 MB) |

    The 417 MB is the etcd data from the data-etcd-0 PVC.

    8.2 Verify Backup¶

    ./scripts/verify-backup.sh hcp-sno-hcp-20260119-132459

    Step 9: Resume HostedCluster Reconciliation¶

    9.1 Resume Command¶

    oc patch hostedcluster sno-hcp -n clusters --type=merge -p '{"spec":{"pausedUntil":null}}'

    9.2 Verify HostedCluster Health¶

    oc get hostedcluster sno-hcp -n clusters
    Result: Available ✅

    What Gets Backed Up¶

    Component Description Backup Method
    HostedCluster CR Cluster configuration K8s resources
    HostedControlPlane CR Control plane settings K8s resources
    NodePool CRs Worker node configuration K8s resources
    Secrets pull-secret, SSH keys, certs K8s resources
    ConfigMaps Configuration data K8s resources
    ServiceAccounts RBAC identities K8s resources
    Roles/RoleBindings RBAC permissions K8s resources
    AgentMachines Cluster API resources K8s resources
    etcd PVC Cluster state data CSI Snapshot → S3

    Troubleshooting¶

    Backup Stuck in WaitingForPluginOperations¶

    • CSI snapshots are being processed
    • Check DataUpload status: oc get dataupload -n openshift-adp

    BackupStorageLocation Not Available¶

    • Check RGW pods: oc get pods -n openshift-storage | grep rgw
    • Check credentials: oc get secret cloud-credentials -n openshift-adp
    • Check velero logs: oc logs -n openshift-adp -l app.kubernetes.io/name=velero

    No Volume Snapshots¶

    • Verify VolumeSnapshotClass has label: velero.io/csi-volumesnapshot-class=true
    • Check CSI plugin in DPA: should include csi in defaultPlugins

    Backup Errors "BackupStorageLocation not found"¶

    • Check storageLocation in backup matches actual BSL name
    • Get BSL name: oc get backupstoragelocation -n openshift-adp
