    Phase 2: Create Gather Script¶

    Date: December 2024
    Status: ✅ Completed

    Overview¶

    This phase creates the script that collects Insights Operator archives from the disconnected SNO cluster.

    Script Created¶

    File: scripts/gather-insights.sh

    What It Does¶

    1. Validates Prerequisites
    2. Checks oc command is available
    3. Verifies cluster connectivity
    4. Confirms Insights Operator is running

    5. Creates required directories

    6. Creates DataGather CR

    7. Creates a DataGather custom resource to trigger data collection

    8. Uses timestamp-based naming for unique identification

    9. Waits for Completion

    10. Polls DataGather status until Completed or Failed

    11. Respects configurable timeout (default: 300s)

    12. Copies Archive

    13. Locates the Insights Operator pod
    14. Finds the latest archive in /var/lib/insights-operator

    15. Copies archive to local temp directory

    16. Queues for Upload

    17. Moves archive to pending/ directory
    18. Creates .meta JSON file with tracking information

    Usage¶

    # With default config location
./scripts/gather-insights.sh

# With custom config
./scripts/gather-insights.sh /path/to/telemetry-sync.env

    Flow Diagram¶

    ┌─────────────────────────────────────────────────────────────────┐
│                    GATHER-INSIGHTS.SH                           │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  1. VALIDATE                                                    │
│     - Check oc command                                          │
│     - Verify cluster connection                                 │
│     - Confirm Insights Operator running                         │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  2. CREATE DATAGATHER CR                                        │
│     apiVersion: insights.openshift.io/v1alpha1                  │
│     kind: DataGather                                            │
│     name: telemetry-sync-{timestamp}                           │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  3. WAIT FOR GATHER                                             │
│     - Poll status every 5 seconds                               │
│     - Timeout: GATHER_TIMEOUT (default 300s)                   │
│     - States: Pending → Running → Completed                     │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  4. COPY ARCHIVE                                                │
│     oc cp openshift-insights/{pod}:/var/lib/insights-operator/  │
│          {archive}.tar.gz → /tmp/telemetry-sync/                │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  5. QUEUE ARCHIVE                                               │
│     - Move to ${PENDING_DIR}/                                   │
│     - Create .meta tracking file                                │
│     - Ready for upload-insights.sh                              │
└─────────────────────────────────────────────────────────────────┘

    Metadata File Format¶

    Each archive gets a .meta file for tracking:

    {
    "cluster_id": "abc123-def456-...",
    "cluster_name": "sno-disconnected",
    "gathered_at": "2024-12-12T03:00:00Z",
    "datagather_name": "telemetry-sync-20241212-030000",
    "archive_file": "abc123-def456-20241212-030000.tar.gz",
    "retry_count": 0,
    "last_attempt": null,
    "status": "pending"
}

    Logging¶

    Logs are written to: ${LOG_DIR}/gather.log

    Log format: 

    [2024-12-12 03:00:00 UTC] [INFO] Starting Insights Gather Operation
[2024-12-12 03:00:01 UTC] [INFO] Cluster: sno-disconnected
[2024-12-12 03:00:02 UTC] [INFO] Creating DataGather CR: telemetry-sync-20241212-030000
...

    Error Handling¶

    Error Cause Resolution
    oc command not found OpenShift CLI not installed Install oc on homelab-server
    Cannot connect to cluster KUBECONFIG invalid Verify kubeconfig path
    Insights Operator not found Operator not deployed Check operator status
    Gather operation timed out Slow network/cluster Increase GATHER_TIMEOUT
    No archive found Gather didn't produce output Check DataGather status manually

    Cleanup¶

    The script automatically cleans up: - Deletes the DataGather CR after completion - Removes temp files on exit (success or failure)
