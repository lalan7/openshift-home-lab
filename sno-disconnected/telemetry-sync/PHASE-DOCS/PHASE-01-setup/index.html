    Phase 1: Setup Folder Structure and Configuration¶

    Date: December 2024
    Status: ✅ Completed

    Overview¶

    This phase creates the folder structure and configuration templates for the telemetry sync automation.

    Folder Structure Created¶

    sno-disconnected/telemetry-sync/
├── README.md                           # Full documentation
├── .gitignore                          # Exclude secrets and runtime data
├── config/
│   └── telemetry-sync.env.template     # Configuration template
├── scripts/
│   ├── gather-insights.sh              # Gather Insights archive (Phase 2)
│   ├── upload-insights.sh              # Upload with retry (Phase 3)
│   ├── process-queue.sh                # Queue processor (Phase 4)
│   └── health-check.sh                 # Red Hat API health (Phase 4)
├── systemd/
│   ├── telemetry-sync.service          # Main service (Phase 5)
│   ├── telemetry-sync.timer            # Daily timer (Phase 5)
│   └── telemetry-retry.service         # Retry service (Phase 5)
├── PHASE-DOCS/
│   ├── PHASE-01-setup.md               # This file
│   ├── PHASE-02-gather.md              # Gather script docs
│   ├── PHASE-03-upload.md              # Upload script docs
│   ├── PHASE-04-queue.md               # Queue processor docs
│   ├── PHASE-05-systemd.md             # Systemd setup docs
│   └── PHASE-06-slack.md               # Slack integration (future)
└── queue/                              # Created at runtime
    ├── pending/                        # Archives awaiting upload
    ├── uploaded/                       # Successfully uploaded
    └── failed/                         # Failed after max retries

    Configuration Setup¶

    Step 1: Copy the Template¶

    cd ~/sno-disconnected/telemetry-sync/config/
cp telemetry-sync.env.template telemetry-sync.env

    Step 2: Get Required Values¶

    # Set kubeconfig
export KUBECONFIG=~/sno-disconnected/auth/kubeconfig

# Get Cluster ID
oc get clusterversion -o jsonpath='{.items[].spec.clusterID}'

# Get cloud.openshift.com token from pull-secret
oc extract secret/pull-secret -n openshift-config --to=- 2>/dev/null | \
  jq -r '.auths["cloud.openshift.com"].auth'

    Step 3: Edit Configuration¶

    vim telemetry-sync.env

# Fill in:
# - CLUSTER_ID
# - CLOUD_TOKEN
# - Verify KUBECONFIG path

    Step 4: Create Queue Directories¶

    source telemetry-sync.env
mkdir -p "${PENDING_DIR}" "${UPLOADED_DIR}" "${FAILED_DIR}" "${LOG_DIR}"

    Verification¶

    # Check structure
tree ~/sno-disconnected/telemetry-sync/

# Verify config loads without errors
source ~/sno-disconnected/telemetry-sync/config/telemetry-sync.env
echo "Cluster ID: ${CLUSTER_ID}"
echo "Queue Dir: ${QUEUE_DIR}"
